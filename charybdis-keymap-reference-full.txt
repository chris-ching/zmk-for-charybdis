Legend
------
- TRNS = transparent
- NONE = intentionally unused
- Thumb rows are shown separately
- Layer numbers:
  0 = Base
  1 = Nav
  2 = Mouse
  3 = Media
  4 = Num
  5 = Sym
  6 = Fun

Physical Thumb Clusters
-----------------------

Left thumb cluster
Top row:    [ BSPC ] [ MO(5) ] [ LCLK / LT(2) ]
Bottom row: [ LALT ] [ LGUI ]

Right thumb cluster
Top row:    [ MO(1) ] [ SPACE ]
Bottom row: [ RET ]

Notes:
- MO(1) = momentary Nav layer while held
- MO(5) = momentary Sym layer while held
- LT(2, LCLK) = tap for left click, hold for Mouse layer
